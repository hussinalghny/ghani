# منصة غني أكاديمي — Ghani Academy LMS

منصة كورسات (موقع + لوحة تحكم + API للتطبيق) مبنية بـ **Laravel 11 + MySQL**، بتصميم بسيط على طريقة Apple وهوية غني أكاديمي.

---

## ماذا يوجد بالمنصة

| الجزء | المحتوى |
|---|---|
| الموقع | الرئيسية، الأقسام، صفحة الكورس، مشغل الدروس، كورساتي، المحفظة، الشهادات، الإعدادات والأجهزة |
| الموبايل | تصميم Mobile-first مع شريط تبويبات سفلي مثل iOS |
| لوحة التحكم `/admin` | إحصائيات، كورسات، فصول ودروس (سحب وإفلات)، رفع فيديو مباشر لـ Bunny، أقسام، مدربين، قسائم، طلاب، موزعين، إعدادات الحماية |
| بوابة الموزعين `/reseller` | الموزع يصدر قسائم من رصيده بخصم، يطبعها كروت، ويتابع المباع والمستخدم |
| API `/api/v1` | كل شيء يحتاجه تطبيق Flutter (انظر `API.md`) |
| الشهادات | تصدر تلقائيا عند إكمال الكورس، برقم `GCA-YYYY-0000` ورابط تحقق عام |

## الحماية من التسريب

| الطبقة | كيف تشتغل |
|---|---|
| روابط فيديو موقعة | Bunny Stream مع Token Authentication؛ الرابط ينتهي بعد 120 دقيقة (قابل للتغيير) |
| علامة مائية متحركة | اسم الطالب ورقمه فوق الفيديو، تتحرك كل 4 ثواني. أي تسريب يبين صاحبه |
| ملء الشاشة المحمي | ملء الشاشة على غلاف المشغل وليس على الفيديو، حتى ما تختفي العلامة المائية |
| ربط الأجهزة | كل حساب على عدد أجهزة محدد (افتراضيا 2). الجهاز الجديد يترفض إلا إذا الإدارة صفرت الأجهزة |
| جلسة واحدة | الدخول من متصفح أو تطبيق جديد يطلع الجلسة القديمة (يمنع مشاركة الحساب) |
| حد فتح الدروس | 40 درس بالساعة افتراضيا. يوقف أدوات السحب الآلي للفيديوهات |
| حماية المتصفح | منع القائمة اليمنى، واختصارات الحفظ وأدوات المطور، وإيقاف الفيديو عند مغادرة التبويب، وحجب عند PrintScreen، وإيقاف الفيديو إذا انحذفت العلامة المائية |
| ملفات الدروس | محفوظة خارج `public` وتتحمل برابط موقع صالح 10 دقائق فقط |
| التطبيق | الـ API يرجع `prevent_screenshots: true`؛ فعل `FLAG_SECURE` بأندرويد وكشف تسجيل الشاشة بـ iOS |

> **ملاحظة صريحة:** ما توجد حماية ويب تمنع تصوير الشاشة 100%. أقوى ردع هو العلامة المائية لأنها تكشف المسرب، وأقوى منع هو DRM. إذا خطتك بـ Bunny تدعم **MediaCage DRM** فعّله من لوحة Bunny بدون أي تغيير بالكود.

### إعداد Bunny Stream
1. أنشئ **Video Library** من bunny.net.
2. من **API**: انسخ `Library ID` و `API Key`.
3. من **Security**:
   - فعّل **Embed view token authentication** وانسخ المفتاح إلى `BUNNY_EMBED_TOKEN_KEY`.
   - بـ **Allowed domains** أضف دومين المنصة فقط.
   - فعّل **Block direct URL file access**.
4. للتطبيق (HLS): من الـ Pull Zone التابع للمكتبة فعّل **Token Authentication**، وضع الهوست بـ `BUNNY_CDN_HOST` والمفتاح بـ `BUNNY_CDN_TOKEN_KEY`.

## القسائم (قابلة لإعادة البيع)

- **قسيمة رصيد:** تنضاف لمحفظة الطالب، ويشتري بيها أي كورس.
- **قسيمة كورس:** تفتح كورسا محددا مباشرة.
- الكود 12 حرف (`XXXX-XXXX-XXXX`) بدون الأحرف المتشابهة، ويستخدم مرة واحدة فقط (مع قفل قاعدة البيانات ضد الاستخدام المزدوج).
- محاولات الإدخال محدودة: 5 بالدقيقة و30 بالساعة لكل حساب، ضد التخمين.
- **الموزعون:** المكتبات والمحلات تصير حسابات بنوع «موزع قسائم» مع نسبة خصم. الإدارة تضيف رصيدا للموزع، والموزع يصدر القسائم من بوابته (تنخصم الكلفة بعد الخصم) ويطبعها كروت A4 ويبيعها.
- الإدارة تقدر تصدر دفعات مباشرة، وتخصصها لموزع، وتصدرها Excel، وتطبعها، وتعطل دفعة كاملة إذا انسرقت.

## التشغيل محليا

```bash
composer install
cp .env.example .env        # إذا ما انعمل تلقائيا
php artisan key:generate
# عدل بيانات قاعدة البيانات في .env
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

الدخول للوحة التحكم: الرقم والباسورد من `ADMIN_PHONE` و `ADMIN_PASSWORD` في `.env`. **غيّر الباسورد بعد أول دخول.**

الـ seeder يضيف 4 أقسام و3 كورسات تجريبية (الدفاع الذكي، موقعك الأول بيدك، تطبيق خلال شهر) بدروس بدون فيديو. احذفها أو عدلها من اللوحة.

## النشر على Hostinger بدون SSH

1. **جهز النسخة الكاملة:** ارفع المشروع على GitHub، ومن Actions شغل **Package ready ZIP**. نزل `ghani-academy-ready.zip` من Artifacts، وهي بيها مجلد vendor.
2. **أنشئ قاعدة بيانات** من hPanel ← Databases ← MySQL.
3. **ارفع الملف** من File Manager إلى `public_html` وفك الضغط هناك. ملف `.htaccess` الموجود يحول الطلبات لمجلد `public` ويمنع الوصول لملف `.env`.
4. **افتح** `https://دومينك/install.php`، وهو يفحص السيرفر ويطلب بيانات القاعدة والأدمن، وينشئ كل شيء.
5. **احذف** `public/install.php` بعد التثبيت. المعالج يتقفل تلقائيا بكل الأحوال.
6. **(اختياري) Cron Job** من hPanel كل دقيقة: `php /home/USER/public_html/artisan schedule:run`

> إذا رفعت النسخة بدون vendor، المعالج يعرض زر «تثبيت المكتبات تلقائيا» ينزل Composer ويشغله داخل PHP.
